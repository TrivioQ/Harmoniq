# Community clients: Go and Python

Thin clients for the Harmoniq registry REST API (OAS-03). Neither has dependencies beyond its standard library. Each has one method for every operation in [`docs/openapi.json`](../../docs/openapi.json); the methods are generated by [`scripts/generate-clients.mjs`](../../scripts/generate-clients.mjs). Responses are JSON. Errors carry the registry's error envelope (`code`, `message`, `details`).

Method names come from the HTTP method and the path. A path that ends in a parameter adds `By…`:

| Operation                                           | Go                                                          | Python                                                        |
| --------------------------------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------- |
| `POST /api/workspaces/{ws}/modules/{module}/deploy` | `PostWorkspacesModulesDeploy(ctx, ws, module, body, query)` | `post_workspaces_modules_deploy(ws, module, body=…)`          |
| `GET /api/workspaces/{ws}/modules/{moduleRef}`      | `GetWorkspacesModulesByModuleRef(ctx, ws, ref, query)`      | `get_workspaces_modules_by_module_ref(ws, ref)`               |
| `GET /api/manifest/{ws}/{hostApp}/{env}`            | `GetManifestByWorkspaceSlugAndHostAppSlugAndEnv(…)`         | `get_manifest_by_workspace_slug_and_host_app_slug_and_env(…)` |

Query parameters (filters, pagination) go in `query`. Request bodies are documented in the [API reference](../../docs/api-reference.md).

## Go

```go
import harmoniq "github.com/harmoniq-dev/harmoniq-go"

c := harmoniq.New("https://registry.acme.dev", os.Getenv("HARMONIQ_API_KEY"))
res, err := c.PostWorkspacesModulesPromote(ctx, "acme", "checkout", map[string]any{
	"fromEnvironment": "staging",
	"toEnvironment":   "production",
}, nil)
if harmoniq.IsStatus(err, http.StatusLocked) {
	// production is frozen
}
var version struct{ ID, Version string }
_ = res.JSON(&version) // 202 means it waits for approval: {"status":"pending_approval",…}
```

## Python

```python
from harmoniq import Client, HarmoniqError

client = Client("https://registry.acme.dev", api_key=os.environ["HARMONIQ_API_KEY"])
try:
    res = client.post_workspaces_modules_rollback("acme", "checkout", body={
        "environment": "production",
        "previous": True,
    })
    print(res.json()["version"])
except HarmoniqError as err:
    print(err.status, err.code, err.message)
```

## Develop

```bash
pnpm run clients:generate                                # after the API changes
(cd go && go test ./...)
(cd python && python -m unittest discover -s tests)
```

CI fails when the generated files are out of date. The clients are published from their own repositories (`harmoniq-dev/harmoniq-go`, and `harmoniq-client` on PyPI); copy each directory there and tag a release.
